# UI / UX

## Direção visual
O sistema deve transmitir organização e confiança, sem cara de template genérico.

### Usar
- fundo neutro;
- blocos brancos discretos;
- cantos levemente arredondados;
- bordas finas;
- tipografia grande o bastante para uso operacional;
- cabeçalho simples;
- badges de status;
- ícones apenas quando ajudarem na leitura.

### Evitar
- gradientes;
- glassmorphism;
- animações desnecessárias;
- 10 cards coloridos na tela;
- excesso de dashboards antes da lista de trabalho;
- linguagem como `workflow`, `entity`, `record` para usuário final.

## Tela Nova Solicitação
Ordem ideal:
1. título `Nova solicitação`;
2. solicitante mostrado como informação, não como campo editável;
3. equipamento;
4. setor;
5. tipo de manutenção;
6. descrição do problema;
7. apontamentos;
8. anexos;
9. botão principal.

No celular, tudo em uma coluna.

## Dashboard PCM
Topo:
- Aguardando PCM
- Em análise
- OS abertas
- Canceladas

Depois: fila de trabalho. A lista é mais importante que os gráficos.

## Textos
Preferir:
- `Aguardando análise do PCM`
- `Em análise pelo PCM`
- `OS aberta no TOTVS`
- `Solicitação cancelada`

Evitar mensagens frias como:
- `Operação concluída com sucesso.`

Preferir:
- `Solicitação enviada.`
- `Você assumiu esta solicitação.`
- `OS 123456 vinculada à solicitação.`
